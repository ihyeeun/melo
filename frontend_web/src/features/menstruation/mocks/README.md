# 월경 기록 MSW 목 데이터

개발 서버에서는 MSW가 기본으로 활성화됩니다. 목업을 끄려면 `VITE_ENABLE_MSW=false`를 사용합니다.

목 데이터는 `menstruation.fixtures.ts`에 API 응답 형태 그대로 작성되어 있습니다.

- 진행 중인 최근 회차 1개
- 종료된 이전 회차 6개
- `2026-08-22`의 `있음` 상세 기록 1개

가장 최근 회차 시작일은 `2026-08-21`입니다. 회차 조회 목은 요청한 `date` 이전의 데이터만 최신순으로 정렬해 `limit`만큼 반환합니다. 생성·수정·삭제 요청에 따라 fixture 자체가 변경되지는 않습니다.
