# 월경 기록 MSW 목 데이터

개발 서버에서는 MSW가 기본으로 활성화됩니다. 목업을 끄려면 `VITE_ENABLE_MSW=false`를 사용합니다.

목 데이터는 `menstruation.fixtures.ts`에 API 응답 형태 그대로 작성되어 있습니다.

- 진행 중인 최근 회차 1개
- 종료된 이전 회차 6개
- 각 회차의 시작일 `있음` 기록
- 종료된 회차의 종료 확인용 `없음` 기록

목 데이터의 기준일은 `2026-08-19`입니다. MSW는 고정 응답만 반환하며 생성·수정·삭제 요청에 따라 데이터를 변경하지 않습니다.
